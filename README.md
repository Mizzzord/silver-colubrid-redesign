# Серебряный полоз — новая версия сайта

Локальная пересборка сайта silver-colubrid.ru. Дизайн: белый, чёрный и зелёный, оригинальный логотип, крупная типографика, авторская композиция первого экрана и исходные фотографии каталога.

## Запуск

```sh
python3 scripts/serve.py
```

Открыть http://127.0.0.1:4173/. Сервер доступен только на этом компьютере. Готовый сайт находится в `dist/` и не требует установки зависимостей для просмотра.

## Содержимое

- 663 товара в 14 категориях, с исходными названиями, ценами, фотографиями, характеристиками и информационными вкладками.
- 11 статей, информация о компании, вакансии, отзывы, вопросы и ответы, оплата, доставка, гарантия, контакты и юридические документы.
- Три отдельные страницы реальных направлений: литьё, изготовление по эскизам и оптовые поставки.
- Поиск, сортировка, пагинация, фотогалереи, избранное, сравнение и корзина с изменением количества.
- Составление письма с заявкой и скачивание списка изделий. Письмо отправляет сам посетитель в своей почтовой программе.
- Все доступные дополнительные материалы старого сайта сохранены по прежним путям; они доступны через карту сайта. Старый демонстрационный текст раздела услуг сохранён отдельно в `/archive/services/`.

## Границы готовности

Это готовая статическая версия интерфейса и содержимого. Она не подключена к закрытой серверной части 1С-Битрикс, действующим платежам, учётным записям и обработке заказов. Переходы в действующий магазин обозначены явно; его корзина заполняется отдельно. Не изображается успешная отправка заявки или оплата без обращения к серверу.

Публикация, изменение домена, действующего сайта и production-данных не выполнялись. Для замены действующего сайта потребуется доступ к его проекту/Битрикс и настройкам обработки заказов, затем отдельное разрешение на публикацию.

Сведения и цены — снимок публичного исходного сайта от 16 сентября 2026 года. Семь товаров имеют цену 0 ₽ в оригинале; значение сохранено, стоимость нужно уточнять у компании. В исходной карте сайта есть устаревшие демонстрационные разделы и недоступные адреса; отчёт с исходными HTTP-ошибками находится в `source/reports/crawl.json`. Недоступное содержимое не выдумывалось. Политики доступны по адресам с `.php`; их неверные ссылки из старого подвала исправлены в новой версии.

## Сборка и проверка

Для повторной сборки нужны Python 3 и зависимости из `requirements.txt`:

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/build.py
.venv/bin/python scripts/validate.py
node --check dist/app.js
```

`src/layout.html` — общий каркас; `src/home.html` — главная; `dist/style.css` и `dist/app.js` — оформление и взаимодействия; `scripts/build.py` — генерация всех страниц. Подготовленное содержимое находится в `source/prepared.json.gz` (сжатый снимок разделён на файлы .part00–.part04; сборщик читает их автоматически). Исходные снимки страниц и медиаматериалы сохранены локально. Отчёты перечисляют страницы, исходные ошибки, медиа и результаты проверки сохранности товарных данных.

`scripts/collect.py` и `scripts/prepare.py` предназначены для отдельного повторного сбора публичного содержимого; обычная пересборка сайта не выполняет сетевые запросы.

## Визуальные материалы

Оригинальный логотип и 2142 изображения перенесены с исходного сайта. `dist/assets/hero.png` — художественная композиция, созданная встроенным Imagegen на основе оригинального изображения совы и лягушки. Она используется только как имиджевый визуал; фотографии карточек товаров не заменены. Точный промпт записан в `source/hero-prompt.txt`. Шрифт Manrope сохранён локально.

Поиск по каталогу также доступен через опциональный WebMCP-инструмент `search_silver_colubrid_products` в поддерживающих браузерах; инструмент только читает каталог и не отправляет заявки.
